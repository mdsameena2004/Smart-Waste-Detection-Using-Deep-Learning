# Smart Waste Classification Using Deep Learning

## Project Overview
Smart Waste Classification is a deep learning project that classifies waste images into different categories automatically. It helps users identify waste types and supports proper waste segregation and recycling.

## Technologies Used
- Python
- TensorFlow
- MobileNetV2
- Google Colab
- Transfer Learning

## Waste Categories
The model classifies waste into six categories:
1. Cardboard
2. Glass
3. Metal
4. Paper
5. Plastic
6. Trash

## Model
This project uses the MobileNetV2 deep learning model with transfer learning to classify waste images.

## Dataset
The project uses a resized waste image dataset containing six waste categories.

## Project Objective
The main objective is to automate waste classification and encourage effective waste management and recycling.
